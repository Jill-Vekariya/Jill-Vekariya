I build machine learning systems end to end: from offline experiments with time-aware evaluation to versioned FastAPI services with CI, Docker and recorded results. My work spans recommendation, retrieval, fraud detection, agent evaluation and infrastructure reliability, and every project ships with a live browser demo.
